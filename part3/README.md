# Part 3 - Programming a server with NodeJS and Express

This directory contains exercise solutions for Part 3 of Full Stack Open 2023.

## Overview
The exercises focus on implementing a backend server using Node.js and Express, including:
- Setting up a simple web server
- RESTful APIs
- MongoDB integration
- Backend deployment

## Running the applications
Each subdirectory contains separate exercises. To run them:

1. Navigate to the exercise directory
2. Install dependencies: `npm install`
3. Start the server: `npm start`
  - For development: `npm run dev`
